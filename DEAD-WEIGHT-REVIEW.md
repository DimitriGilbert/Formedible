The 5 worst offenders:

1. **R1-1 — double dynamic-text resolution** (`use-formedible.tsx:762/:793` → `renderField` `:641`). Every top-level field's label/description/placeholder/help/section is interpolated twice per render, and a token-shaped *value* (a user typing `{{otherField}}`) is re-interpolated on the second pass, leaking other fields' values into UI text. Probe: `{a:'{{b}}', b:'LEAKED'}`, label `X {{a}}` → pass 1 `X {{b}}` → pass 2 `X LEAKED`.
2. **R1-3 — validator churn** (`validation.ts:577-591`, `use-formedible.tsx:409-423`). Three byte-identical closures built per field per render, plus full validator objects built per field per invalid-field pass — and those passes run on every keystroke once a submit has been attempted.
3. **R1-9 — O(F×T×F) visibility rebuilds** (`field-visibility.ts:116-124` via `use-formedible.tsx:443/:465`). `isFieldLocationVisible` rebuilds the tab-visibility entry list per field per pass; the invalid-entry and unmounted-error loops make it quadratic-plus in field count per keystroke.
4. **R2-1 + R2-2 — parser settings theater** (`parser-config-schema.ts`, `parser-settings.tsx`, `formedible-parser.ts:141/:1424`). Four user-editable controls (`enableZodParsing`, `showDetailedErrors`, `maxCodeLength`, `maxNestingDepth`) affect nothing: the first two are read by no consumer at all, the last two reach only the system-prompt text — the parser's own length gate is a hardcoded 1M constant and no call site forwards the depth option.
5. **R3-2 — RawOutputPanel eager debug work** (`raw-output-panel.tsx:42-43,167-171`, mounted per completed assistant message via `chat-messages.tsx:65`, doubled by `sidebar-content.tsx:39-53`). Re-parses the form code (without the parser config), walks/redacts the entire event log, and JSON.stringifies all of it on every render — all while its `<details>` payload is collapsed.

Runner-up: R3-1 (O(n²) stream-event accumulation per 16 ms flush in `chat-interface.tsx:160`).

Needs-decision list (18 items — removals that change behavior or public surface; see §4 batch C for the choices): R1-4, R1-10 (partial), R1-18, R2-1/R2-2 (wire vs delete), R2-4 (clone = prototype laundering), R2-5, R2-6, R2-8, R2-10, R2-14, R2-15, R3-4, R3-5 (partial public API), R3-6, R3-7, R3-11, R3-14/R3-15 (file deletions), R3-16 (partial: dead props).
